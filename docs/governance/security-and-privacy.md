# Security and privacy

This repository is a sanitized, history-free snapshot of **Week UP**.

## Intentionally excluded

- Original Git history and author metadata
- Local runtime databases, backups, user profiles, learning records, and AI job data
- Provider configuration, environment files, credentials, keys, and certificates
- Logs, caches, dependencies, build output, test artifacts, and temporary files

Only committed product source, tests, documentation, and non-sensitive assets from source commit `b92bbc9fb8ec47493eed328859cd1de3b1cc36e2` were considered for export.
Do not commit real user data or credentials to this repository.
