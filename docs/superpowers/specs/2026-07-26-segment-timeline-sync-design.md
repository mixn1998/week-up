# 分段执行同步时间线设计

## 行为

- 已安排时间的普通任务点击完成后直接完成，不弹出实际执行时间确认。
- 已安排时间的分段任务完成一段后，立即用该段的计划时段显示在 Timeline。
- 未配置时间的任务完成时保留实际执行日期与时段确认，并以确认值显示在 Timeline。
- 分段任务只有全部分段完成后才完成整项并发放一次奖励。
- 撤销一个已完成分段时，该段立即从 Timeline 移除；若整项原本已完成，同时撤销整项完成与奖励。

## 数据与投影

- 不新增“部分完成事实”或数据库结构。
- 分段进度继续存放在 `PlanRecord.timeSegments[].completedAt`。
- Timeline 在没有整项完成事实时，投影已完成分段；整项完成后改由 `CompletionFact.actualSegments` 投影，避免重复。
- 已安排时间的完成命令直接采用计划时段；只有 `timeStatus === "unscheduled"` 时才要求用户确认实际时段。

## 验证

- 投影测试覆盖完成第一段后 Timeline 立即出现、未完成段不出现、全部完成后不重复以及撤销后移除。
- UI 测试覆盖已安排任务不打开确认窗口、未配置时间任务仍打开确认窗口。
- 完整类型检查、测试、构建和浏览器核验通过。
