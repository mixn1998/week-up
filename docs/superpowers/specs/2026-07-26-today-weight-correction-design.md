# 今日体重修正设计

## 目标

用户在今日快捷录入体重后，可以进入“体重趋势”页面修正今天的数据。历史日期不可修改。

## 交互

- 体重历史列表中，仅今天的记录显示“修改”按钮。
- 点击后，该行原地切换为紧凑数字输入框，并显示“保存”和“取消”。
- 输入范围沿用现有规则：20–300 kg，精确到 0.1 kg。
- 保存成功后退出编辑状态，最新体重、趋势图和移动平均立即按修正值重算。
- 取消时恢复原值，不写入数据。

## 数据

复用现有 `weight.record` 命令，以今天的本地日期写入新修订。领域层保留旧修订并通过 `supersedesRevisionId` 关联；读模型仍只投影当天最新的有效值。

## 边界与错误

- 非今天的记录不提供修改入口。
- 无效或越界数值时禁用保存。
- 本地持久化服务离线时沿用全局离线保护，不产生本地伪成功。

## 验证

- 领域测试确认同日修订保留历史且只投影最新值。
- UI 源码测试确认只有今日行具有修改入口和行内编辑控件。
- 类型检查、完整测试、生产构建和浏览器视觉核验全部通过。
