# Learning MORE 历史镜像去重修复

## 问题

Learning MORE 已完成课节离开当前课表后，会通过历史日历重新进入同步批次。现有同步只按 `sourceRef` 查找镜像，无法把新的 `learning-more:history:*` 引用与原已完成课表镜像识别为同一次课节，因而新增一条未完成计划。该重复计划进入今日逾期队列，导致逾期数量由 1 错增至 4。

## 修复口径

- 同一课节、同一完成日期的历史镜像与既有已完成课表镜像视为同一记录。
- 保留已有完成事实、实际执行时间、奖励与经验交易。
- 将保留记录的来源引用更新为历史引用，确保后续同步能直接命中。
- 删除新生成的未完成历史重复镜像，不新增或复制完成事实。
- 同一课节在不同日期再次安排时仍保留为不同记录。
- 真正未完成的普通任务和仍在正式课表中的未完成 Learning MORE 课节不受影响。

## 实现与验证

扩展 Learning MORE 历史镜像协调逻辑：以课节 ID 和有效完成事实的上海日期匹配历史镜像，保留完成记录并移除重复项。增加领域回归测试，覆盖旧课表镜像已完成、课表项消失、历史镜像随后出现的流程，并验证逾期投影只剩真实未完成任务。
