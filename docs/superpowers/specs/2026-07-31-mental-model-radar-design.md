# 心智模型雷达总览设计

## 目标

把当前分散的心智模型卡片改造成一个可快速理解的整体结构视图。页面以雷达图为核心，展示不同心智维度在当前版本中的证据强度与稳定度，并允许历史基线与后续月度版本进行对比。

雷达值不代表人格优劣、健康程度或能力高低，只表示现有显著思想与情绪记录对该维度的支持程度。

## 固定维度

雷达图使用八个长期稳定的维度，避免每次分析产生不同轴：

1. 自我观：主体性、自我认同、能动性与边界。
2. 人际观：亲密、合作、差异、信任与关系共创。
3. 权力观：选择权、资源、谈判、规则与结构性影响。
4. 行动观：执行、节奏、风险处理、实践与复盘。
5. 学习观：认知方式、知识结构、验证与理解策略。
6. 价值观：长期价值、贡献、交换、责任与非零和倾向。
7. 生命观：情绪调节、身体经验、欲望、克制与生命力。
8. 世界观：环境、系统、情境、不确定性与整体解释框架。

维度标识使用稳定英文键：

`self`、`relationships`、`power`、`action`、`learning`、`values`、`vitality`、`world`。

## 数据结构

在 `MentalModelVersion` 的分析结果中增加 `dimensionProfile`，原有 `models` 暂时保留为分析来源和迁移兼容数据，但不再直接以卡片方式展示。

每个维度包含：

- `dimension`：稳定维度键。
- `strength`：0–100 的证据强度。
- `confidence`：`low`、`medium` 或 `high`。
- `summary`：该维度的核心信念。
- `defaultJudgments`：常见默认判断。
- `currentStrategies`：当前应对或行动策略。
- `supportingModelKeys`：支撑该维度的已有模型键。
- `changeDirection`：`new`、`stable`、`strengthened`、`weakened` 或 `reframed`。
- `changeSummary`：相对上一版本的变化说明。

历史基线只由已保存的结构化 `models` 生成维度画像，不重新发送历史正文。后续月度版本由当月分析同步生成 `dimensionProfile`。

## 评分口径

`strength` 是可解释的证据强度，不是 AI 主观人格打分。其输入包括：

- 支撑模型的置信度。
- 支撑模型数量。
- 支撑记录覆盖的不同日期数。
- 反证数量。
- 相对上一版本的持续性。

同一天的多条记录按一个记录日计算覆盖度；缺失日期不补值；记录条数不直接等同于发生频率。

历史基线因为不保存正文，只能使用基线生成时已经形成的结构化模型、模型置信度与来源统计。首次转换时生成一个冻结的八维画像，之后不得因前端算法变化而动态改写。

## 页面结构

### 顶部

保留心智模型版本切换条与版本来源说明。

### 雷达总览

主区域为一张大尺寸八维雷达图：

- 当前选中版本使用玫红实线与半透明填充。
- 存在上一版本时使用青色虚线轮廓叠加。
- 图例明确标注“当前版本”和“上一版本”。
- 每个轴直接显示中文维度名。
- 图旁展示“结构最清晰的三个维度”和一段综合画像。
- 图下注明“数值表示记录证据强度，不代表优劣”。

雷达图使用本地 SVG 渲染，不引入新的图表依赖；保证像素边框、颜色和纸张纹理与 Week UP 一致。

### 维度分析

雷达图下方改为纵向维度分析表，不使用独立卡片：

- 每行一个维度。
- 左侧显示维度名称、强度条和变化标签。
- 右侧依次显示核心信念、默认判断、当前策略。
- 默认按强度从高到低排列。
- 前四项展开，其余四项折叠在“展开全部维度”内。

原来的十张模型卡不再出现在主页面。需要追溯时，在维度行的折叠详情中显示支撑模型名称，不展示历史原文。

## 版本比较

- 历史基线没有上一版本，只显示单层雷达。
- 月度版本默认与其 `previousVersionId` 对应版本叠加。
- 版本切换只改变雷达和维度分析，不重算或修改已冻结版本。
- 强化、弱化和重构均只描述证据结构变化，不作心理诊断。

## 兼容与迁移

- 旧版 `MentalModelVersion` 若只有 `models`，通过一次性领域命令生成并冻结 `dimensionProfile`。
- 迁移不得读取或写入历史正文。
- 新分析结果缺少某个维度时仍生成该轴，强度为 0，并明确标注“当前没有足够证据”。
- 旧 `models` 数据继续保留，确保已有月度变化链路和证据关系不丢失。

## 验证

- 八个维度始终按固定顺序渲染。
- 雷达点位、轴标签和图例在桌面端及 390px 窄屏不重叠。
- 历史基线和月度版本均能展示。
- 有上一版本时正确叠加两条轮廓；没有时不渲染空图例。
- 强度为 0、全为 0、部分维度缺失及分析失败状态均有可读界面。
- 历史正文记录数在迁移前后保持不变。
- 类型检查、领域测试、页面结构测试、生产构建及桌面/窄屏视觉检查全部通过。
