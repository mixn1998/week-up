# 时间待配置逾期任务重排修复

## 问题

过去日期、未完成的普通任务即使没有配置具体时间，也会在今日页进入“逾期待处理”。但领域层的逾期判断排除了 `timeStatus === "unscheduled"`，导致界面允许点击“重新安排”，保存时却返回 `plan_not_overdue`。

## 统一口径

- 过去日期、未完成、仍参与逾期队列的普通任务均属于逾期，不以是否配置具体时间为条件。
- 时间待配置的逾期任务可以重新安排到今天或未来。
- 重排后的新任务既可以配置时间，也可以继续保持“时间待配置”。
- Learning MORE 任务和每日重复任务继续遵循现有逾期归属规则。
- 原逾期记录继续冻结保留，新记录继续通过 `overdueSourcePlanId` 与原记录关联。

## 实现与验证

统一领域层与视图层使用的逾期条件，删除领域层对 `unscheduled` 的额外排除。增加领域回归测试，覆盖过去日期的时间待配置任务能够重排，并确认已配置时间、Learning MORE、每日重复、历史冻结及重复重排规则不回归。
