# 属性徽章 XP 增量分析设计

## 范围

本次只修改 Week UP 电脑 Web 端，包含两个彼此独立的需求：

1. 成就图鉴中的完整属性徽章可进入独立增量分析页。
2. 今日、本周、本月现有属性增长汇总附近增加当前周期的总属性增长。

手机端不增加入口或适配。

## 徽章增量分析页

点击成就图鉴中的完整徽章卡片后，在保留侧栏与顶栏的主内容区打开详情页。返回图鉴时保留原分类筛选和展开状态。今日、周/月摘要中的紧凑徽章仍只作展示。

页面采用高密度像素分析驾驶舱：

- 顶部展示徽章、等级、总 XP、等级进度和本月增量。
- 30 日累计阶梯趋势，并与前 30 日比较；前一周期为零时显示本期绝对增量，不显示无意义百分比。
- 最近 4 个自然周的每周 XP 增量。
- 全部当前有效 XP 按项目分类汇总的来源构成。
- 最近 30 日增长活跃日与最长连续增长天数。
- 下方展示当前有效 XP 来源记录，包括完成日期、行动、项目或课程、项目分类和有效 XP。

来源记录按月份连续分组，每组显示条数与 XP 合计。初次显示最近 20 条，使用“继续加载更早记录”追加下一批；界面不使用页码。数据量较大时只渲染可见窗口，并提供本周、本月、全部筛选及年月定位。

## 数据结构与统计

现有 `XpTransaction`、`CompletionFact` 和 `PlanRecord` 继续作为唯一事实来源，不新增第二套持久化 XP 总账，也不需要数据库迁移。

新增只读分析投影 `AttributeXpSource`：

- `attributeId`
- `completionFactId`
- `planId`
- `completedAt`
- `amount`
- `planTitle`
- `projectOrCourse`
- `projectCategory`
- `source`

同一完成事实、同一属性下的所有 XP 交易按净额合并。只展示净额大于零的当前有效来源，且全部来源行金额之和必须严格等于徽章当前总 XP。时间归属使用完成事实的 `completedAt`，不使用后续奖励重算交易的发生时间。

分析投影一次建立计划、完成事实和 XP 交易索引，再生成趋势、周增量、项目分类构成、活跃日和来源列表。无法定位旧计划时使用“历史完成记录”作为标题，保留其 XP。

## 当前周期总属性增长

今日、本周、本月的属性增长区附近新增当前周期合计：

- 今日只汇总上海时区当天的可见属性增长。
- 本周只汇总当前周一至周日范围内的属性增长。
- 本月只汇总当前自然月内的属性增长。
- 当前周期随完成、撤销和 Learning MORE 同步实时更新。
- 查看历史结算周期时，汇总该周期已冻结的 `attributeGains`。

合计直接相加页面已经使用的各属性增量，不建立额外存储，确保总数与单项汇总一致。

## 异常与验收

- 无有效 XP 的徽章仍可进入详情页，各模块显示零状态。
- 已归档徽章仍可查看；彻底删除后不保留入口。
- 项目分类缺失时归入“未分类”。
- 月份或周数不足时展示已有数据，不补造记录。
- XP 获得、撤销、模板奖励重算后，来源合计始终等于徽章总 XP。
- 上海时区的日、周、月边界、30 日趋势、4 周增量、分类构成与活跃日均有回归测试。
- 点击徽章、返回图鉴、筛选、按月分组、连续加载和周期合计均有界面回归覆盖。
